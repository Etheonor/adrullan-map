# Adrullan — fan map

Interactive map of Adrullan Online Adventures with NPC positions observed from
in-game network traffic during the playtest.

- click a zone button to frame it
- wheel = zoom, drag = pan
- search an NPC by name to jump to it
- filter by NPC type (merchant, trainer, banker, artisan, stable, broker)
- generic wildlife and player pets are hidden by default
